## Numbered Findings List

### [HIGH Priority] Hard Gate Violations
*These are non-negotiable standards for accessibility, functional integrity, and core contract.*

1. **R-25 — Color Contrast (WCAG AA Normal Text Failure)**
   `--text-muted: #64748b` on `--bg-dark: #090d16` yields 4.08:1 and on `--bg-surface: #0e1424` yields 3.86:1, failing the WCAG AA minimum ratio of 4.5:1 for normal text in `.contact-label` and `footer`.
   *Target files:* [globals.css](file:///c:/Users/Sedrick/Documents/Portfolio/src/app/globals.css#L33)

2. **R-26 — Interactive Elements (Dead Filter Button)**
   The "Production Platforms" filter pill (`filter === 'web'`) in `Projects.tsx` is a dead control that causes no visible state change because all projects in `data/projects.ts` share the identical category `'web'`.
   *Target files:* [Projects.tsx](file:///c:/Users/Sedrick/Documents/Portfolio/src/components/Projects.tsx#L53-L58), [projects.ts](file:///c:/Users/Sedrick/Documents/Portfolio/src/data/projects.ts#L6-L58)

3. **R-03 — Mobile Responsiveness (Under-Sized Tap Target)**
   The mobile navigation toggle button (`.menu-toggle`) measures only 32×32 px (24px SVG + 4px padding), falling below the mandatory 44×44 px touch target requirement.
   *Target files:* [globals.css](file:///c:/Users/Sedrick/Documents/Portfolio/src/app/globals.css#L259-L266), [Navbar.tsx](file:///c:/Users/Sedrick/Documents/Portfolio/src/components/Navbar.tsx#L62-L68)

4. **R-32 — Keyboard Accessibility (ARIA Tree Conflict on Hidden Slides)**
   In `DepthCarousel.tsx`, inactive slides receive `aria-hidden="true"` while containing interactive focusable buttons (`.depth-carousel__view-btn`), creating an accessibility conflict for screen reader and keyboard navigation.
   *Target files:* [DepthCarousel.tsx](file:///c:/Users/Sedrick/Documents/Portfolio/src/components/DepthCarousel.tsx#L453-L501)

5. **R-37 — Design Direction Required (Missing DESIGN.md)**
   The repository lacks a `DESIGN.md` defining brand identity, mood, deliberate color hierarchy, and explicit liveliness dials (ENERGY / RHYTHM / MOTION).
   *Target files:* Repository root
